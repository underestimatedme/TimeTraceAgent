# 从连接电脑到查看第一个成果

适用：刻迹 Flutter 客户端与 TimeTraceAgent 0.5.2。手机需使用支持“生成并开始”和成果反馈的新版刻迹。

## 先准备什么

- 一台可联网且保持在线的 Mac；手机和电脑不必在同一局域网。
- 在这台 Mac 上安装并登录 Claude Code 或 Codex，确认自己能正常使用。刻迹不会代购额度；工具没额度时任务会等待或报告原因。
- 一个你愿意让 AI 修改的项目目录。第一次用可恢复的小型测试仓库，任务要求里写清楚范围。
- 手机安装刻迹并登录自己的账号。

## 1. 在 Mac 安装 Agent

新绑定最低要求 0.5.1，推荐已发布的 [0.5.2](https://github.com/underestimatedme/TimeTraceAgent/releases/tag/v0.5.2)。Homebrew 0.5.2 公式更新暂缓，不能靠反复 `brew upgrade timetraceagent` 获得该版。

**首次安装**，可用 pipx 从发布 tag 安装。需要 Python 3.9 或更新版本和 Git；如果尚未安装 pipx，可先用已有的 Homebrew 安装 pipx：

```sh
brew install pipx
pipx ensurepath
```

重新打开终端，再运行：

```sh
pipx install "git+https://github.com/underestimatedme/TimeTraceAgent.git@v0.5.2"
tta --version
tta setup
```

如果已通过 **pipx** 安装，可运行同一 `pipx install` 命令并加 `--force`，再核对版本。若之前用 **Homebrew 或源码** 安装，先运行 `which -a tta timetrace` 核对命令来源，不要把两种安装方式混在一起。按 [Agent 安装说明](https://github.com/underestimatedme/TimeTraceAgent#安装)选择维护原方式或迁移；需要帮助时保留版本与命令路径，不要发送令牌、配置全文或私钥。

已有绑定升级后通常无需重新绑定。换了安装路径，需要从正确路径运行 `tta agent install`，让后台服务使用正确版本。

## 2. 把手机和电脑绑定

按 `tta setup` 提示登记项目目录，电脑会显示二维码或 8 位配对码。

1. 手机打开 **AI → 绑定电脑**，扫描电脑二维码；相机不可用时输入 8 位码。
2. 核对电脑名称。手机显示 4 位数字后，**到电脑终端输入**，包括前导零。
3. 手机显示绑定成功后，继续完成电脑上 `tta setup` 的剩余提示，让后台服务启动。
4. 回到手机 AI 页，确认电脑在线、至少一个 AI 终端可用。

码过期或连续输错后请在电脑重新取码，不要把配对码发给别人。

## 3. 一句话开始第一个任务

打开或创建项目，关联这台电脑的项目目录，在项目中输入需求，例如：

> 检查这个项目的 README，把本地启动步骤补充清楚；只修改文档，不提交或推送代码，完成后告诉我改了什么。

选择电脑和可用的 AI，点击 **生成并开始**。生成后会建立工作项并进入执行队列；如果缺少权限、电脑离线或额度不足，要看页面显示的等待原因。

## 4. 去哪里看结果

- **今日 → 需要你处理**：查看需要自己审批、补充或验收的事项。
- **项目 → 工作项 → 进度与结果**：查看执行／等待／失败状态、动态、成果摘要和文件。
- **成果 → 提意见 / 继续修改**：只记录想法用“仅保存意见”；要重新执行用“按意见开始修改”。原成果保留在历史中，新成果需要重新验收。

当前没有系统推送，请返回 App 查看最新状态。不要只等通知。

## 常见卡点

| 现象 | 下一步 |
| --- | --- |
| `tta` 找不到或版本不对 | 重新打开终端，用 `which -a tta timetrace` 和 `tta --version` 核对路径；检查 pipx 的 PATH 提示 |
| 已登录 Claude 但终端仍不可用 | 在电脑运行 `tta agent doctor` 查看具体原因，再回手机刷新；不要反复扫码绑定 |
| 电脑在线但任务不能开始 | 查看项目目录关联、终端状态和任务等待原因；绑定成功不代表工具已登录或有额度 |
| 断网后提交结果未知 | 按页面提示重试同一笔请求，避免重新创建同样任务 |
| 不知道结果在哪里 | 回到对应工作项的“进度与结果”，再打开“成果”或历史记录 |

仍有问题可联系 support@atlaspaces.com，提供 App 版本、Agent 版本、发生时间与脱敏错误文字。不要提供验证码、密钥、完整执行日志或私人项目内容。
