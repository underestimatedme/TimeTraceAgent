# TimeTraceAgent 0.6.7

Run `timetrace config set claude.quota_probe false` to turn off active Claude quota queries and interactive quota collection by the TimeTrace status-line hook. The Runner reads the setting on restart. Run `timetrace statusline --uninstall` to remove the hook and restore any previous custom status line.

The setting lives in `~/.timetrace/config.json`. Homebrew upgrades retain the file and `timetrace agent install` respects the setting. Existing installs default to enabled unless the setting is explicitly `false`.

Codex quota polling and Claude task execution remain available. Claude tasks can still report rate-limit events emitted by Claude Code during execution. Without background readings, Claude quota shown in TimeTrace can be older.

No database, protocol or server upgrade is required. Versions before 0.6.7 do not honor this setting.
