# TimeTraceAgent 0.6.0

Includes the installed f754c50 baseline's heartbeat recovery, durable result outbox and manual-discard audit fixes, plus MCP access for dispatched Claude Code and Codex jobs. Execution protocol remains 2. The server must be upgraded before this Agent.

- Job access is tied to the current attempt and lease. Cancellation and completion revoke it.
- MCP configuration is private (0600), removed at the end of execution, and passes tokens through environment variables rather than command arguments.
- Stream events are parsed before output redaction; uploaded files and binary attachments are checked for the job token. Codex jobs with MCP disable shell snapshots to prevent environment-token persistence.
- `timetrace`, `tts` and the compatible `tta` entry points use the same package.
- Existing pairing and local data remain in the existing TimeTrace home. Do not install a second background service.

Validation before release: 960 Python 3.12 tests completed, with 3 explicitly skipped; true local Claude Code and Codex MCP and dispatched-job tests are documented in [the MCP acceptance record](../mcp-e2e-2026-11.md). These local results do not claim that every installed computer has upgraded.

The Claude adapter continues to append the user's other configured MCP servers. Large default tool catalogs can consume substantial context; this release does not change the user's configuration. Long-lease and multi-job production acceptance remain separate follow-up checks.
