# TimeTraceAgent 0.5.2 发布清单

状态：发布准备，未创建正式 tag / GitHub Release，Homebrew 尚未更新。

## 用户可见变化

- 只读采集已关联的本地 Git 仓库、文档与 GitHub PR/CI，回传到刻迹开发状态和交接流程，不改用户仓库或调用 AI。
- Git 读取失败时报告失败，不误报为干净仓库。
- 新事件使用领取/续租响应的 `server_now` 加单调时钟，避免电脑时钟较快导致回执被拒绝；已入队事件原样重放。兼容旧服务端，但回退时仍依赖本地时钟；租约截止判断也仍需要正确的系统时间。
