# TimeTraceAgent 0.6.13

本地队列遇到已占用的 Claude 或 Codex 时，会继续按优先级寻找可执行的任务。已绑定会话的任务等原工具空闲后续跑，未指定工具的新任务可以使用另一空闲工具。整机允许并行时，云端任务优先使用其他空位，把本地队列可用的共享空位留到最后。并行 Runner 在工作结束时会唤醒领取循环，再向 Valley 请求任务。

- `timetrace agent sessions` 按更新时间列出本机的工作会话和计划检查点。
- `timetrace agent sessions --task <本地任务号>` 显示每次运行的序号、开始时间、工具和会话指纹。同一工具的相同指纹表示队列记录了同一个会话标识。加上 `--json` 可读取时间戳和退出码。
- 启用本机会话记入后，可能属于当前任务的文件延后检查，较早的会话可以先同步。`timetrace agent doctor` 显示本轮暂缓检查的数量。

通过 Homebrew 安装的用户运行 `brew update && brew upgrade timetraceagent`。等正在执行的任务结束后，运行 `timetrace agent install` 重载后台 Runner，再用 `timetrace agent doctor` 核对状态。
