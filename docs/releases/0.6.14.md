# TimeTraceAgent 0.6.14

Claude Code 在 TimeTrace 派来的任务里调用 AskUserQuestion 提问时，问题会出现在网页工作项的「执行需要你的决定」里，带着 AI 给出的选项。你选好回答后，电脑把你选的选项交给 Claude，它接着往下做。

- AI 的问题总是交给你回答，本机规则和「本任务内同类都允许」都不会替你回答。
- 回答按 Claude 自己的问题和选项文字还原，你选的只能是 AI 给出的选项。
- 以下情况电脑会拒绝本次提问，并提示 Claude 不要替你选择，说明需要你决定什么后结束，或换一种不依赖这个回答的做法：
  - 你选择不回答；
  - 问题 10 分钟内没有人回答；
  - 批准时没有附带合规的回答。
- 问题格式不对，或长到无法完整转给你时，电脑直接拒绝并告诉 AI 原因。
- 库存上报 `questions_version: 1`。服务端只把回答发给这一版本及以上的电脑。
- Codex 的普通任务没有中途提问的工具，行为不变。

网页的「试跑一次」用这项能力验证「AI 发问 → 你回答 → 它继续」。发布前没有在真实的 Claude 进程上实测这一问答：回答格式依据 Claude Agent SDK 文档，测试使用仓库内模拟的 Claude 进程。升级后，请在网页上用「试跑一次」核对。

通过 Homebrew 安装的用户运行 `brew update && brew upgrade timetraceagent`。等正在执行的任务结束后，运行 `timetrace agent install` 重载后台 Runner，再用 `timetrace agent doctor` 核对状态。使用前需要更新配套的 TimeTrace 用户控制台和 Valley。
