# TimeTraceAgent 0.6.11

TimeTrace 现在能看到三样新东西：AI 对自己这一步做得怎样的说明、你在电脑上直接用 AI 做了什么，以及每次运行用掉多少 token。

- **AI 完成说明。** 执行步骤可以在 `.timetrace/out/result.json` 里写 `report`，给出结论（`success`、`needs_review` 或 `blocked`）、摘要、没做完的事和建议复核的地方。电脑端先脱敏再截断（摘要最多 1000 字，其余每项最多 300 字、最多 10 项），随结果交给 Valley，控制台在步骤和验收处显示。格式不对时忽略并在完成说明里注明。它只供参考，不改变验收结论。
- **本机 AI 会话记入（默认关闭）。** 在 TimeTrace 网页「设备」页打开后，你在终端或桌面端直接用 Claude Code / Codex 做的事会记入「按日回顾」。只上传每段会话的元数据：工具、会话 id 摘要、工作区、模型、分支、起止时间、提问次数、token 合计和改动文件数。对话文字（包括标题）、命令输出、文件路径和内容都不上传。关掉开关后立即停止，已上传的记录可在同一页删除。
- **AI 用量。** 每次运行结束（完成、失败、被中断、等额度、取消或停止）时，上报本次用掉的输入、输出、缓存读取、缓存写入 token 和模型名。控制台的「AI 用量」页按日、项目、来源和模型汇总，并按 models.dev 2026-11-16 的公开标价估算费用。估算不等于账单：订阅套餐不按 token 收费。续跑的 Codex 会话只计本次新增部分。拿不到可靠起点时不上报，不做猜测。
- **ACP 客户端，不派发 Gemini CLI 和 Cursor。** 新增只依赖 Python 标准库的 Agent Client Protocol 客户端。Gemini CLI 和 Cursor 可以登记，并在 `timetrace agent doctor` 里查看，但它们的零付费和凭据隔离无法核验，核验结论固定为未通过，TimeTrace 不会给它们派发任务。

这些功能需要配套更新的 TimeTrace 用户控制台和 Valley。用量统计已在 macOS 上用 Claude Code 2.1.325 和 Codex 0.165.0 的真实运行核对，Codex 包括续跑。已有配对和工作区配置继续沿用。

Homebrew 用户可运行 `brew update && brew upgrade timetraceagent`。等当前任务结束后，运行 `timetrace agent install`，再用 `timetrace agent doctor` 检查运行版本。
