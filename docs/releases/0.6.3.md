# TimeTraceAgent 0.6.3

A running AI process is no longer stopped by one failed lease renewal.

- While the process runs, a failed renewal request or a gate check that fails once (for example `claude auth status` timing out) used to cancel the process at once, fence the job and delete its checkpoint. The step was lost half way and needed manual recovery.
- Now the Agent keeps the process running and retries while the current lease has more than 15 seconds left. A cancel, a runner stop, or a lease about to lapse still stops it at once.
- Every held renewal and every stop is written to `daemon.log` with its reason, and a failed renewal request is logged with its error.
- Checks before the process starts are unchanged: nothing starts without a verified zero-spend billing state.

Execution protocol remains 2, and the server does not need an upgrade. Validation before release: the Python 3.12 test suite.
