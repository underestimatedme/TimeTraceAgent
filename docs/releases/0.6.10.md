# TimeTraceAgent 0.6.10

在 TimeTrace 用户控制台打开工作项，即可选择已配对的 Mac、登记的 Git 工作区，以及本机已登录的 Codex 或 Claude Code。执行始终使用隔离的 Git 工作树。换到手机浏览器后，可在同一工作项接着发送指令、处理审批并查看交付。

- 运行中可追加指令。空闲时可沿用同一厂商会话进行只读追问，或继续执行并提交新版成果。追加指令以厂商回执为准，回执丢失时显示待确认。
- 支持范围明确的单次工具审批。审批绑定当轮原始请求，过期后拒绝。审批和最终验收各自独立。
- 执行轮交付时核对 Git 提交。工作项保留交付版本和变化摘要，并沿用现有验收流程。

此功能需要配套更新的 TimeTrace 用户控制台和 Valley。已在 macOS 上使用 Codex 0.165.0 和 Claude Code 2.1.325 验证。已有配对和工作区配置继续沿用。工作副本被更改或上一次执行进程的退出状态存疑时，恢复可能需要在本机人工核对。

Homebrew 用户可运行 `brew update && brew upgrade timetraceagent`。等当前任务结束后，运行 `timetrace agent install`，再用 `timetrace agent doctor` 检查运行版本。
